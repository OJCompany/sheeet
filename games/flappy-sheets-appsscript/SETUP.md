# 셀 플래피 — 구글 시트 안에서 실행하기 (Apps Script)

> 게임은 구글 시트 위에 뜨는 **모달 다이얼로그(HTML 패널)** 안에서 60fps로 돌아갑니다.
> "링크 열고 → 메뉴 클릭 → 플레이", 크롬 확장 설치 없음.

## 설치 (약 3분)

1. **새 구글 시트** 생성 → [sheets.new](https://sheets.new)
2. 메뉴 **확장 프로그램(Extensions) > Apps Script**
3. 기본 `Code.gs`에 **`Code.gs` 내용 전체 붙여넣기**
4. 편집기 왼쪽 **파일 [+] > HTML** 클릭 → 파일명 **`Game`** (확장자 없이) 입력
   → 생성된 `Game.html`에 **`Game.html` 내용 전체 붙여넣기**
5. 💾 저장 → 시트 탭으로 돌아가 **새로고침(F5)**
6. 새 메뉴 **🎮 SHEEET > 셀 플래피 실행 🐤** 클릭
   - 처음이면 권한 승인 창 → 본인 구글 계정으로 허용
7. 시트 위에 게임 다이얼로그가 뜸 ✅

## 플레이

- **Space** 또는 게임판 **클릭/탭**으로 날갯짓
- 파이프 통로를 통과하면 +1점, 부딪히면 재시작
- 새·파이프·하늘 전부 **셀 색칠**로 렌더링 (이미지 0장)

## 속도 조절 (원하면)

`Game.html` 상단의 상수를 바꾸면 됩니다 (단위: 칸/초):

| 상수 | 의미 | 기본값 | 더 쉽게(느리게) |
|---|---|---|---|
| `SPEED` | 파이프 이동 속도 | `2.6` | ↓ 낮추기 (예: 2.0) |
| `GRAV` | 중력(낙하 가속) | `5.2` | ↓ 낮추기 (예: 4.0) |
| `FLAP` | 날갯짓 세기 | `-2.4` | 절대값 살짝 ↓ |
| `GAP` | 통로 높이(칸) | `6` | ↑ 키우기 (예: 7) |
| `SPAWN_GAP` | 파이프 간격 | `13` | ↑ 키우기 |

## 왜 이 방식인가 (심사 포인트)

| 렌더링 위치 | 부드러움 | 방법 |
|---|---|---|
| **HtmlService 패널** ⭐ (이 방식) | ✅ 60fps | 패널 안 클라이언트 JS가 `requestAnimationFrame`으로 셀 색칠 |
| 진짜 시트 셀에 직접 | ❌ 1~2fps | Apps Script `setValue` — 서버왕복·재계산·할당량 |

> 결론: **셀 액션게임은 "시트 안 HTML 패널"에서 렌더**하는 게 정답.
> 이 패널 자리에 Firebase를 붙이면 실시간 멀티도 가능(REALTIME.md 옵션 A).
