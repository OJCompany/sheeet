# 오목 (Gomoku) — 구글 시트 설치 가이드

> 시트 네이티브 · 턴제 · 2인 대전. 서버·설치·가입 없음. 링크 공유만으로 플레이.

## 설치 (약 2분)

1. **새 구글 시트 생성** → [sheets.new](https://sheets.new)
2. 상단 메뉴 **확장 프로그램(Extensions) > Apps Script**
3. 편집기의 기존 코드를 지우고 **`Code.gs` 내용 전체를 붙여넣기** → 💾 저장
4. 시트 탭으로 돌아가 **새로고침(F5)**
5. 새로 생긴 메뉴 **🎮 SHEEET > 새 게임 (오목판 생성)** 클릭
   - 처음 실행 시 권한 승인 창이 뜨면 본인 구글 계정으로 허용
6. 15×15 오목판 완성 ✅

## 플레이

- **빈 칸을 클릭 → 아무 키나 입력하고 Enter** → 현재 차례의 돌(●/○)이 자동으로 놓임
- 흑(●) → 백(○) 번갈아 진행. 오른쪽 **상태 칸(R2)**에 다음 차례가 표시됨
- 가로·세로·대각선 중 **5목** 완성 시 "○ 승리! 🎉"

## 2인 대전 (링크 플레이)

- 우상단 **공유** → **"링크가 있는 모든 사용자" + 편집자** 권한으로 링크 복사
- 상대에게 링크 전달 → 같은 시트에서 번갈아 착수
- 상대의 돌이 **준-실시간(1~2초)**으로 내 화면에 나타남 (구글 공동편집 기본 동작)

## 동작 원리 (심사 어필 포인트)

| 요소 | 구현 |
|---|---|
| 입력 감지 | `onEdit(e)` 심플 트리거 — 셀 편집 시 발동 |
| 차례 관리 | 턴 카운터 셀(R3), 짝수=흑 / 홀수=백 |
| 동시 착수 충돌 | **`LockService`** 문서 잠금으로 직렬화 |
| 잘못된 수 방지 | `e.oldValue`로 이미 놓인 칸 덮어쓰기 원복 |
| 승리 판정 | 착수점에서 4방향 5연속 스캔 |
| 렌더링 | 순수 셀 — 배경색 + ●/○ 이모지 (이미지 0장) |

> **왜 턴제인가?** 리서치 결과(`RESEARCH.md`) — Apps Script `onEdit`는 빠른 연속 입력을 흘리고(이벤트 ~2개만 큐잉) 저지연 푸시가 없어, 시트 네이티브 게임은 턴제가 정답. 오목은 태생이 턴제라 시트에 완벽히 맞는다.

## 한계 / 참고

- 플레이어 식별은 하지 않음(차례만 강제) → 상대가 내 차례에 두는 "매너"는 신뢰 기반. 필요 시 `Session.getActiveUser().getEmail()`로 흑/백 이메일 고정 가능(같은 도메인 한정).
- 무르기·금수(3·3 등) 룰은 MVP 범위 밖.
