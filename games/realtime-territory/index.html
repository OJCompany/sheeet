2인 실시간 테스트 방법
이 파일을 같은 브라우저(크롬 권장)에서 탭 2개로 엽니다 → 한 탭은 🔵 파랑, 다른 탭은 🔴 빨강 선택 → 아무 탭에서 게임 시작 → 두 탭에서 칸을 마구 클릭하세요. 상대가 먹은 칸이 즉시 반영됩니다.

동시성 처리 (Figma식 Last-Writer-Wins): 두 명이 같은 빈 칸을 거의 동시에 클릭하면, 나중에 저장된 쪽이 그 칸을 갖습니다(마지막 쓰기 승리). 이게 리서치에서 확인한 실시간 멀티의 핵심 충돌해결 방식이에요.

동기화 방식: 이 프로토타입은 localStorage 공유 상태 + BroadcastChannel로 탭 간 실시간 동기화 — 서버 0대. 실서비스에선 이 자리를 Firebase Realtime DB(WebSocket)로 그대로 교체하면 인터넷 너머 플레이어끼리 동일하게 동작합니다.
