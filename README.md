# sheeet 🎮

엑셀(VBA 매크로)로 만든 게임 모음. 게임마다 폴더 하나씩, 클론 받아서 xlsm 열면 바로 플레이할 수 있습니다.

## 게임 목록

| 게임 | 설명 | 실행 파일 |
|---|---|---|
| [섯다](seotda/) | 2~5인 화투 섯다. 콜/하프/따당/다이 베팅, 땡잡이·암행어사·구사 특수 규칙, 난이도 3종 AI | `seotda/섯다.xlsm` |

## 공통 실행 방법

1. Windows + 데스크톱 엑셀(2016 이상)에서 해당 게임의 `.xlsm`을 연다.
2. 노란 보안 경고 표시줄에서 **"콘텐츠 사용"** 클릭 (매크로 허용).
3. 플레이. 자세한 규칙은 각 게임 폴더의 README 참고.

> ZIP으로 다운로드한 경우 Windows가 매크로를 차단할 수 있습니다.
> 파일 우클릭 → 속성 → "차단 해제" 체크 후 열어주세요. `git clone`으로 받으면 이 과정이 필요 없습니다.

## 새 게임 추가 규칙

- 게임 하나 = 폴더 하나 (`게임이름/`)
- 폴더 안에 실행 파일(`.xlsm`), `README.md`, 빌드 스크립트(`build/`)를 둔다
- 브랜치에서 작업 후 main으로 PR
