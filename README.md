# 엑셀 섯다 (섯다.xlsm)

엑셀 매크로(VBA)로 만든 섯다 게임. **2~5인**(나 + AI 1~4명, 한게임 섯다의 5인 대결 기준)을 골라 대전합니다. 실제 돈이 아닌 게임 포인트만 사용하는 오락용입니다.

## 실행 방법

1. `섯다.xlsm`을 엑셀에서 연다.
2. 노란 보안 경고 표시줄에서 **"콘텐츠 사용"** 클릭 (매크로 허용).
3. 타이틀 화면에서 **인원(2~5인)**과 난이도(초급/중급/고급)를 골라 시작.

## 게임 방법

- 시작 자금 10,000P, 판마다 참가자 전원이 기본 판돈 100P씩 냅니다.
- 각자 2장을 받고, 내 패와 족보는 바로 공개됩니다.
- 베팅: **콜**(판돈 맞추기/체크) · **하프**(판돈의 절반 레이즈) · **따당**(직전 레이즈의 2배, 앞선 레이즈가 있을 때만 버튼이 나타남) · **다이**(포기)
- 차례는 플레이어부터 시계 방향(AI 1 → AI 2 → …)으로 돌며, 레이즈가 나오면 나머지 전원이 다시 응답합니다.
- 전원이 콜하면 패를 공개해 족보가 가장 높은 사람이 판돈을 가져갑니다. 한 명 빼고 전부 다이하면 남은 사람이 가져갑니다.
- 최고 족보가 동점이면 판돈이 다음 판으로 이월되어 재경기합니다.
- 파산한 AI는 탈락하고, 모든 AI가 파산하면 완승입니다.
- 내 자금과 전적은 파일에 자동 저장됩니다(저장하고 닫으면 이어하기 가능). AI 자금은 게임 시작 때마다 초기화됩니다.

## 족보 (높은 순)

38광땡 > 18광땡 > 13광땡 > 장땡~1땡 > 알리 > 독사 > 구삥 > 장삥 > 장사 > 세륙 > 갑오~1끗 > 망통

게임판 우측에 족보 순위표가 항상 표시됩니다.

## 특수 규칙 (v2)

- **땡잡이** (3월+7월): 상대의 1땡~9땡을 잡고 승리합니다. 장땡·광땡은 못 잡습니다.
- **암행어사** (4월 열끗+7월 열끗): 13·18광땡을 잡습니다. 38광땡은 못 잡습니다.
- **구사** (4월+9월): 최고 족보가 알리 이하면 그 판은 무효가 되고 판돈이 이월됩니다(재경기).
- **멍텅구리구사** (4월 열끗+9월 열끗): 최고 족보가 장땡 이하면 재경기.
- 특수 패는 내 족보 라벨에 함께 표시됩니다(예: "망통·땡잡이").

## AI 난이도

- **초급**: 패의 강도만 보고 판단
- **중급**: 판돈 대비 콜 비용까지 고려, 가끔 블러핑
- **고급**: 플레이어의 베팅 성향(하프 빈도)을 학습해 대응 + 블러핑

AI마다 게임 시작 시 공격성 개성이 무작위로 부여되어 같은 난이도라도 조금씩 다르게 플레이하고, 상대가 많을수록 신중해집니다.

AI 성향은 숨김 시트 `Data`의 파라미터(공격성/블러핑확률/다이임계)로 조정할 수 있습니다.

## 프로젝트 구조

```
PLAN.md           설계 문서
섯다.xlsm         완성된 게임 (이 파일만 배포하면 됨)
build/build.ps1   빌드 스크립트 (시트·도형 생성 + VBA 주입 + 자체 테스트)
build/vba/*.bas   VBA 소스 (modMain 게임루프, modDeck 덱, modHand 족보,
                  modBetting 베팅, modAI 인공지능, modUI 화면, modSound 효과음,
                  modSave 저장, modTest 자체테스트)
```

## 다시 빌드하기

```powershell
pwsh -File build\build.ps1
```

- Excel 설치 필요. 빌드 시 "VBA 프로젝트 개체 모델 신뢰"(HKCU AccessVBOM=1)를 자동 설정합니다.
  플레이만 할 때는 필요 없으며, Excel 옵션 > 보안 센터에서 다시 끌 수 있습니다.
- 빌드는 족보 판정·덱·AI 자체 테스트(SelfTest)를 통과해야 저장됩니다.

## 알려진 제약

- 효과음은 Windows 시스템 사운드를 사용합니다.
- 구사 재경기는 조건 충족 시 자동 선언됩니다(선택권 없음).
- 올인 사이드팟은 없습니다. 레이즈가 남은 참가자의 최소 자금으로 제한되어 전원이 항상 콜할 수 있습니다.
