# 퀴즈쇼 (SLIIIDE Quiz Show) — 작업 현황 & 남은 일

2026-07-24 기준. 새 게임 모드 "퀴즈쇼"를 만들어 Apps Script 프로젝트에 배포한 상태.

## 완료된 것 ✅

- **게임 코드 작성**: `apps-script/slides-quiz.gs` + `apps-script/slides-quiz-sidebar.html`
  - 카테고리 4종(넌센스/상식/속담·사자성어/음식) × 문제 8개씩, 보기 4지선다
  - 게임 흐름: 로비 → **카테고리 투표**(20초, 아바타를 카드에 올려 다수결, 동표는 추첨)
    → 문제 7개(각 25초, 정답 카드 위 아바타 +10점) → 점수 순위(동점 공동 순위)
  - 탈락 없음. 우측 패널이 SCOREBOARD(점수 내림차순)로 동작
  - 운명의 문과 같은 아키텍처(아바타 드래그 + 호스트 사이드바 2초 tick), 같은
    드라이브 아바타 폴더(`운명의문_아바타`) 재사용
- **배포**: Apps Script 프로젝트의 Code.gs를 퀴즈 코드로 교체(리포와 동일), HTML 파일
  `slides-quiz-sidebar` 신규 생성. 메뉴 [🧠 퀴즈쇼] 정상 노출
- **동작 확인**: 보드 생성 → 참가 3명(쥐/소/호랑이) → 게임 시작 → 카테고리 투표 카드
  4장 렌더링 → 투표 판정(당선 카드 초록 하이라이트)까지 실제로 돌려서 확인함
- 테스트용 임시 함수는 배포본에서 제거 완료, 보드는 로비 상태로 리셋해둠

## 남은 일 ⬜

1. **문제 라운드 실전 검증**: 투표 이후 흐름(문제 출제 → 25초 카운트다운 → 정답
   판정/점수 부여 → 다음 문제 → 최종 우승 배너)은 코드로는 완성됐지만 실제로
   끝까지 돌려보진 못했음. 사이드바([컨트롤 열기])를 켜두면 자동 진행되므로
   2명 이상 참가시켜 한 판 돌려볼 것
2. **사이드바 표시 확인**: 새 사이드바(qz* 함수 연동)의 상태 표시(카테고리·문제
   n/총, 로그)가 실제 게임 중 제대로 갱신되는지 확인
3. **문제 은행 보강**: 지금은 카테고리당 8문제뿐. 원하는 주제/문제를
   `slides-quiz.gs`의 `QZ_BANK`에 추가하면 됨 (형식: `{ q: '문제', c: [보기4개], a: 정답인덱스 }`)
4. **밸런스 튜닝(선택)**: 문제 수(`QZ_NUM_QUESTIONS`), 제한시간(`QZ_ROUND_SEC`),
   점수(`QZ_SCORE`) 상수로 조절 가능. 후반 문제 배점 2배 같은 변형도 고려
5. **운명의 문과 공존(선택)**: 현재 Apps Script에는 퀴즈쇼만 배포됨(운명의 문 코드는
   리포에 보존). 둘 다 쓰려면 onOpen을 합쳐 메뉴 두 개를 띄우도록 수정 필요
6. **git 커밋**: 이번 세션 변경분이 커밋 전임 —
   새 파일(`slides-quiz.gs`, `slides-quiz-sidebar.html`, 이 문서), 투명 배경으로 교체된
   `12지신_캐릭터_파일/*.png`, 그리고 이전부터 있던 `slides-doors.*` 수정분
