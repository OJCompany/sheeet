## 남은 일 ⬜

1. **문제 은행 보강**: 지금은 카테고리당 8문제뿐. 원하는 주제/문제를
   `slides-quiz.gs`의 `QZ_BANK`에 추가하면 됨 (형식: `{ q: '문제', c: [보기4개], a: 정답인덱스 }`)
   — 리포 수정 후 Apps Script 편집기의 Code.gs에도 반영 필요
2. **밸런스 튜닝(선택)**: 문제 수(`QZ_NUM_QUESTIONS`), 제한시간(`QZ_ROUND_SEC`),
   점수(`QZ_SCORE`) 상수로 조절 가능. 후반 문제 배점 2배 같은 변형도 고려
3. **운명의 문과 공존(선택)**: 현재 Apps Script에는 퀴즈쇼만 배포됨(운명의 문 코드는
   리포에 보존). 둘 다 쓰려면 onOpen을 합쳐 메뉴 두 개를 띄우도록 수정 필요
